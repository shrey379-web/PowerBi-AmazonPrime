# 🚀 My First Power BI Dashboard – Amazon Prime Video Analysis 📊

I'm thrilled to share my **first dashboard project in Power BI**! This project was a fantastic introduction to interactive data visualization and business intelligence.

---

## 🎬 Project Overview

This **Amazon Prime Video Dashboard** was created using a provided dataset to deliver key insights through a variety of visual tools. The focus was on designing a clean, intuitive, and dynamic dashboard that brings streaming trends and performance to life.

---

## 📌 Key Highlights

- 🔄 **Interactive Insights:** Enables users to drill down into metrics and explore the data more deeply  
- 📡 **Real-Time Design Principles:** Structured to represent live or regularly updated data  
- 🧑‍💻 **User-Centric Design:** Clean layout and intuitive visuals for quick decision-making

---

## 📊 Visualizations Included

- 🃏 **Cards** – Displaying total key metrics  
- 🗺️ **Map** – Geographic distribution of content or viewership  
- 📊 **Clustered Bar Chart** – Content type or genre comparisons  
- 🍩 **Donut Chart** – Proportional breakdowns  
- 🎗️ **Ribbon Chart** – Rank-based data visualization

---

## ✨ What I Learned

- Real-time data visualization concepts and storytelling  
- Efficient use of Power BI visuals, slicers, filters, and formatting  
- Designing dashboards with both business value and user experience in mind
